## Now: Resonance AI

**Resonance AI** is an AI film studio that turns stories and documents into finished short films—music videos, commercials, and short-form video. A production agent plans, generates, and edits shot by shot on one canvas. It is a creative film agent from document, not a general chatbot.

## Also: Marlin and crm.sdk

**Marlin AI** is a custom personal CRM on the same site: a proactive customer-relation secretary for hire, stack, and booking.

**[crm.sdk](https://github.com/bunkernine/crm.sdk)** (`@bunkernineai/crm.sdk`) is a typed Postgres CRM library for AI agents. Contacts, companies, deals, activities, search, and reports via `createCrm()`—no GUI, no MCP.
